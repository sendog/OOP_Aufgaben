Playlist-Manager

In dieser Aufgabe ist ein Programm-Gerüst für die Verwaltung von Playlists vorgegeben. Dieses Gerüst
sollen Sie um Variablen und Methoden ergänzen, so dass die Playlist-Verwaltung vollständig lauffähig
ist.

Teil 1
1) Laden Sie zunächst alle Quellcode-Dateien in dem Zip-Verzeichnis herunter und importieren Sie
diese in die Programmierumgebung Ihrer Wahl.
3) Alle Stellen, an denen Sie Code ergänzen sollen, sind durch TODOs gekennzeichnet. Bitte löschen
Sie keinen vorhandenen Code. An der Benutzeroberfläche in UI.cs müssen Sie keine Änderungen
vornehmen.
4) Einige zu implementierende Methoden sind im Quellcode kommentiert. Berücksichtigen Sie diese
Kommentare bei Ihren Implementierungen.

Tipp: Konzentrieren Sie sich zunächst darauf, das Programm zum Laufen zu bringen. Dazu müssen Sie
u.a. diejenigen Methoden implementieren (und ggf. Variablen hinzufügen), die aus dem vorgegebenen
Quellcode aufgerufen werden.

Teil 2
Drei Methoden in Playlist.cs sind mit dem Zusatz „Teil 2“ gekennzeichnet. Das Programm aus Teil 1 ist
auch ohne diese Methoden lauffähig.
1) Implementieren Sie nun diese Methoden.
2) Passen Sie die Benutzeroberfläche in UI.cs so an, dass die neuen Funktionalitäten über das Menü
genutzt werden können.
